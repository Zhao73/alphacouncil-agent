# AlphaCouncil Agent v0.9.1 — Quick Council Preview (Non-GA)

`v0.9.1` is a bounded quick-council release for users who want the selected method-seat
views, the core analyst views and recent company/industry news in roughly ten minutes. It
is published to npm's `next` dist-tag and marked as a GitHub prerelease. It is not a
PersonaPack production-GA release.

## Why this release exists

The public RKLB acceptance runs exposed two different latency failures:

- `0.9.0-solo-test.1` took 81m54s. Two evidence workers each consumed a 20-minute timeout,
  then the run spent another 42m55s on downstream method/debate/PM work before ending
  incomplete.
- `0.9.0-solo-test.2` improved to 23m12s, but one malformed evidence response was known at
  2m08s and the run still spent almost 16 additional minutes on downstream synthesis before
  returning incomplete.

Those are workflow failures, not investment conclusions. The default full workflow was
also the wrong product shape for a user asking for a short method/analyst/news brief.

## Quick council contract

Set `council_mode=quick` in both the selection and the analysis call. The complete 26-seat
catalog is still displayed before research; quick accepts one to four explicit stable IDs
and does not accept `all`. The receipt is bound to the symbol, prompt, language and mode.

The plugin-managed headless topology is:

1. bounded deterministic grounding;
2. four evidence workers launched together: `market_data`, `earnings_deep_dive`,
   `valuation_long_short`, `news_industry_management`;
3. one to four selected method seats launched in one wave when model execution is needed;
4. one Bull and one Bear statement launched in parallel;
5. one short Portfolio Manager synthesis;
6. deterministic report assembly and standard artifacts.

The hard end-to-end ceiling is 600,000ms and may only be lowered. Internal caps are 20s
for grounding wait, 210s per evidence worker, 90s per selected method worker, 90s per
Bull/Bear worker, 90s for the PM and a 20s finalization reserve. The ceiling guarantees a
bounded outcome, not a successful analysis: missing evidence can produce `degraded` or
`incomplete`.

Recent-news display accepts only dated sources in the 120 days up to `as_of`. Undated,
future and stale items are counted as gaps. Method-seat text is the recorded output of a
provisional method lens in this run; it is not a quotation from the named person.

## Scope and quality

Quick reports use `quick_v1`, not the full 23-section contract. The contract requires a
conclusion, four-seat work log, one-round debate record, system-owned Master Bench,
earnings/management signals, recent company and industry news, valuation, price conditions,
risks, position, data gaps, confidence and a source table.

`report_quality=passed` means only that `quick_v1` structure passed. It does not mean:

- the run was a full council;
- every evidence seat succeeded;
- three-round exact Q&A ran;
- adversarial source/numeric/counterevidence verifiers ran; or
- the named-investor packs became validated method models.

A deliverable quick run with missing seats has terminal status `degraded`, not `complete`,
and receives one system-owned failure ledger. If the PM fails, no fallback `Hold` is
produced: the decision is `NEEDS_MANAGER_REVIEW` and the rating is unavailable.

## Full-mode failure control

Full remains the default eight-evidence-seat, selected-method, three-round council when its
mandatory evidence barrier succeeds. If mandatory evidence remains missing after the one
bounded parse-only retry, 0.9.1 stops before the method/debate/PM model calls, writes an
auditable incomplete package and reports `downstream_model_calls_skipped=true`. It no longer
spends another full synthesis budget on a run that cannot pass its execution gate.

## Other release fixes

- Cross-seat prompt compaction removes `raw_text` and `report_markdown`; full PM input keeps
  bounded per-round summaries and exact Q&A.
- Quick claim/source compaction preserves source references and records omitted counts.
- `degraded` is terminal for polling and startup recovery.
- Evidence-barrier telemetry distinguishes `evidence_degraded` from `evidence_complete`.
- The nested package parity check removes inherited `npm_config_dry_run`, so
  `npm publish --dry-run` creates and validates a real temporary tarball.

## Assurance boundary

- Build channel: `solo_test`.
- `production_eligible=false`.
- `method_model_eligible=false`.
- Physical provisional packs: 26.
- Provisional `operator_lens`: 26.
- Operational seats: 0.
- Validated `method_model` seats: 0.

The formal GA gate remains fail-closed. This feature release does not supply the missing
human approvals, signed experiments, four-host evidence, cutover or rollback proof.

The release is verified with offline deterministic quick/full integration tests and a real
installed-tarball smoke. It deliberately does not rerun another paid full-market RKLB
council.
