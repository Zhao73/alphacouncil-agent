# AlphaCouncil Agent v0.9.0-solo-test.2 — RKLB acceptance fixes

This is an official installable **0.9.0 solo-test prerelease**, not production GA. It is a
corrective release based on an independent real RKLB run of `0.9.0-solo-test.1`.

## What the acceptance run proved

- The mandatory 26-seat catalog and one-use selection receipt worked. The run selected
  Buffett, Druckenmiller, Damodaran and Taleb from the frozen catalog.
- The shared deterministic grounding and six successful analyst packets produced useful,
  sourced work. Two analysts timed out, so the run correctly remained incomplete.
- All four selected v3 seats declined because their exact required typed facts were absent.
  That fail-closed behavior is correct; the release does not alias historical FCF to owner
  earnings, historical growth to a forward DCF path, IV to realized volatility, or a credit
  level to liquidity impulse.
- The real run exposed host timeout, recursive worker, failed-packet contamination, status
  ambiguity, source-lineage collision and cross-host manifest issues. This release fixes
  those implementation defects.

## Runtime fixes

- Background `analyze_symbol` returns a durable pollable run handle; startup terminalizes
  dead-process orphan runs instead of leaving clients polling forever.
- Leaf `codex exec` workers keep native search while ignoring globally installed plugins and
  MCP servers.
- Failure diagnostics are stored separately from investment evidence.
- Partial evidence and per-round debate completion have explicit events and status.
- The third debate round uses cross-fed Round-2 questions and fails closed unless both
  sides return three ordered `{question, answer}` bindings whose question text matches the
  corresponding opponent Round-2 question exactly and whose answer is non-empty.
- SEC Company Facts records have stable source identity across multiple derived metrics.
- Chinese PM reports recognize the emitted `Master席位分歧处理` heading as the required
  Master Bench section, and chat handoff summaries truncate at sentence/word-safe Unicode
  boundaries.
- Headless status distinguishes source-ID presence from adversarial verifier execution.
- Codex MCP wiring is isolated from OpenCode compatibility importers, and the npm package
  includes the declared Codex icon.
