# AlphaCouncil Agent v0.9.0-solo-test.3 — RKLB post-acceptance hotfix

This is an installable **0.9.0 solo-test prerelease**, not production GA. It fixes two
defects found by an independent end-to-end RKLB run against the public
`0.9.0-solo-test.2` package.

## What the public `.2` run proved

- The mandatory 26-seat chooser and one-use receipt selected Buffett, Druckenmiller,
  Damodaran and Taleb from a frozen catalog.
- The durable asynchronous analysis path completed in 23m12s, versus 81m54s for the
  preceding `.1` acceptance run.
- Seven of eight evidence seats completed and the debate passed exact Round-2-to-Round-3
  question/answer binding.
- Source-ID closure was complete for the 108 recorded source entries. Headless verification
  correctly identified its scope as source-ID presence only; adversarial verification was
  not run.
- All four selected deterministic v3 method seats returned `out_of_scope` because their
  exact typed-fact contracts were not satisfied. No proxy aliases were invented to unlock
  them.

The run was still a **failed acceptance result**: one worker returned concatenated JSON
objects and the PM omitted Master Bench. The run status was incomplete and its report
quality was `needs_revision`.

## Runtime fixes

- Code-zero malformed JSON is isolated as a parse failure with empty claims, sources and
  raw evidence.
- A single parse-only retry receives only the original source-bounded task and a stricter
  transport instruction. It receives only the remaining configured worker budget and
  cannot consume a third attempt.
- Malformed output is retained only in a separate diagnostic containing a bounded parse
  context and output hash. The file is mode `0600` on POSIX; Windows ACL ownership is not
  independently verified by this release.
- Master Bench is a system-owned deterministic section: PM-authored aliases are relabelled
  as non-authoritative commentary, a prior system section is replaced, and exactly one
  hash-marked table of the recorded seat IDs, stances and verdicts is assembled before
  report-quality validation.
