# AlphaCouncil 1.9.1

This patch fixes terminal outcome reporting and a false rejection at the company-evidence barrier.

## Root cause and changes

Unavailable coverage gaps were mirrored into open questions before normalization. Reader escaping then changed only the open-question text (`Q&A` became `Q&amp;A`), so byte-equality validation rejected otherwise matching gap disclosures. The normalized coverage gap now receives the same escaping. This preserves the unavailable disposition and all source, retrieval and critical-evidence gates; it does not invent a transcript or waive the bounded repair/deadline contract.

Terminal progress previously counted artifact existence, including failure placeholders, and showed the background process's `completed` state as a second research status. The patch counts successful outcomes, shows timeouts and skipped stages, and renders the complete saved handoff below progress. A live transition reveals the conclusion once; subsequent refreshes preserve the reader's position. Full report views remove disclosure markup and machine sentinels without truncating recorded statements. Structured primary/final failure diagnostics are accessible without raw response bodies.

Existing research artifacts are not rewritten, and failed runs are not silently restarted. The patch does not convert an earlier incomplete run into a completed investment analysis. The 26 PersonaPacks remain provisional version 0.9.4.

## Verification boundary

The release PR and workflow records carry final test/build/publication results. Verification covers the escaping regression, strict missing-retrieval rejection, failed-versus-successful artifact accounting, inline conclusion paging and live transition, plus packaged terminal walkthroughs. It does not claim a new paid full-council acceptance run or resolution of every provider timeout.
