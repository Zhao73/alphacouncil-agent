# AlphaCouncil Agent v0.9.0-solo-test.1 — PersonaPack v3 solo-test

This is the first public **0.9.0 solo-test prerelease**. It is an official installable
build, but it is not a production-GA claim and does not represent 26 independently
validated investor models.

## Highlights

- Mandatory per-run master selection on Claude Code, Codex, OpenCode and Grok, supporting
  one seat, any combination, ranges or all 26 seats.
- One-use, hash-bound selection receipts enforced by the MCP server before research starts.
- 26 physical PersonaPack v3 solo-test packs and 52 executable deterministic
  `provisional_derived_proxy` tools.
- Five requested seats added to the 26-seat catalog: Damodaran, Ackman, Cathie Wood, Pabrai
  and Jhunjhunwala.
- Hash-bound AI source review capsules for 32 source candidates, three-stage semantic review,
  three-role cross-review for all 52 formulas, and eight deterministic machine simulations.
- Master Bench reporting, typed-fact grounding, fail-closed veto/coverage behavior, replay
  protection and explicit `N_eff=null` disclosure when resolved outcomes are insufficient.
- A real installed-package smoke test that starts the MCP server, opens the 26-seat catalog,
  confirms Buffett, creates a bounded plan and proves receipt replay is rejected.

## Assurance boundary

- 26/26 seats are provisional `operator_lens` packs.
- `operational`: 0; `method_model`: 0.
- Human source approvals: 0; human formula approvals: 0; human signatures: 0.
- Formal A/B/C/D13/D26/E/H experiment evidence: not complete.
- Live four-host E2E release evidence: 0/4.
- Formal production GA remains fail-closed.

The package is therefore published under npm's `next` dist-tag and GitHub marks this as a
prerelease. Install this exact build with either:

```bash
npm install -g alphacouncil-agent@0.9.0-solo-test.1
npm install -g alphacouncil-agent@next
```

The default `latest` dist-tag remains on the production-facing 0.8.0 line. The stable
`0.9.0` version is deliberately reserved for a future build that satisfies the formal
PersonaPack v3 release gates.
