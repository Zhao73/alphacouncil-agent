# v1.6 ChatGPT Work and evidence-quality plan

This plan separates a usable private ChatGPT Work integration from public app hosting and
from claims about the 26 provisional method seats. Passing source tests is necessary; it is
not proof of a successful live council, investment accuracy, or profitability.

## Product decision

The first ChatGPT Work release is tool-only. It reuses the canonical AlphaCouncil runtime
through a remote Streamable HTTP adapter and does not add an iframe or duplicate research
engine. The Work surface exposes 26 chat-safe tools:

- the receipt-bound method-selection handshake;
- durable background `analyze_symbol` and bounded `read_run` polling;
- diagnostics, screening, quotes, macro, filings, news, sources, options, social and
  industry tools.

It hides eight visible-host recorders or synchronous long-run tools that hosted ChatGPT
cannot supervise. The 26 Work tools are not the 26 method seats; both counts must always be
labelled.

## Evidence gates

### W1 — source and protocol

- Official MCP SDK, stateless Streamable HTTP `/mcp`, health endpoint and localhost Host
  protection.
- Human-readable title, input schema, output schema and complete annotations on every
  exposed tool.
- Request-scoped response transport so concurrent HTTP calls cannot capture one another.
- Official SDK client tests initialize, list, call and reject synchronous councils.
- Canonical stdio remains dependency-free and keeps all 34 tools.

Status: implemented locally; merge and exact GitHub CI remain separate evidence.

### W2 — private ChatGPT Work developer-mode E2E

- Start the local gateway and a short-lived secure HTTPS tunnel.
- Register the endpoint in ChatGPT Work developer mode and save the exact generated
  `asdk_app_...` technical ID; do not invent one in source.
- Prove the hosted ChatGPT conversation can list the catalog, call delayed quote/news tools,
  complete one selection receipt, start one quick council, and poll the same `run_id` to a
  terminal handoff.
- Stop the tunnel and retain a redacted transcript with source SHA, timestamps, calls,
  terminal status and artifact hashes.

Status: not run until the source PR is reviewed and the user confirms the browser actions.

### W3 — 26-method response evidence

The current source proves 26 physical provisional packs, one canonical catalog entry per
seat, deterministic stance execution, isolated voice-call orchestration and fail-closed
persistence. It does not yet prove 26 successful real model voices or that those answers are
correct and behaviorally distinct.

Run three increasingly expensive checks:

1. **Small live panel:** 4 methods across at least 3 point-in-time cases. Check source-ID
   validity, frozen-stance agreement, language, non-impersonation and no unsupported figure.
2. **Full live panel:** all 26 methods on one frozen evidence packet. Require 26 real
   `model_voice` outcomes; any timeout, empty result, deterministic substitute or schema
   failure makes the full run incomplete before debate and PM.
3. **Repeated blinded panel:** at least 3 cases with repeated identical inputs. Measure
   method-policy fidelity, counterfactual sensitivity, duplicate rationale, unique cited-source
   contribution and inter-seat agreement. Keep effective independent-seat count `N_eff=null`
   until the preregistered resolved-outcome protocol is actually satisfied.

Only after those gates may a seat be promoted from provisional `operator_lens` toward a
validated method model. A named investor's public method is never presented as the person's
current words, endorsement or portfolio.

### W4 — 15-minute experience claim

- Full fast remains a 15-minute queue-to-terminal-persistence ceiling, not a demonstrated
  successful-completion SLA.
- Preserve one parallel evidence wave, parallel selected methods, parallel Bull/Bear within
  each round and deterministic persistence reserve.
- Capture real attempt events and critical path for at least 10 fast runs across operating
  companies, ETFs and indices. Report complete/degraded/incomplete separately.
- Advertise “15-minute successful result” only if the preregistered success/latency target is
  met; otherwise advertise the truthful terminal bound and offer quick mode as the smaller
  contract.

### W5 — public or team-wide hosting

No-Go until all exist:

- OAuth 2.1/PKCE and account linking;
- tenant-separated filesystem/object storage, credentials and audit records;
- per-tenant concurrency, cost and rate limits;
- stable HTTPS domain, monitoring, backup and rollback;
- privacy policy, terms, data retention/deletion path and security review;
- app-review evidence from W2–W4.

The private gateway currently uses the owner's local Codex login and filesystem. A temporary
tunnel URL is not authentication and must never be left running as a public service.

## Promotion and marketing boundary

Source merge, GitHub main, About text, GitHub Release, npm publication, ChatGPT Work E2E and
method-quality evidence are independent layers. Update each only after its own gate. The
truthful near-term promise is: sourced public-data research, selectable provisional method
lenses, explicit Bull/Bear challenge, durable audit artifacts and visible data gaps. Do not
promise profit, higher returns, real-time market data, expert endorsement, or 26 independent
models.
