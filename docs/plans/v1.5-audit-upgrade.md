work order for the implementing agent. The reviewing agent checks every acceptance

## Background (audit findings being fixed)

1. Version drift: repo main is 1.4.1, GitHub release v1.2.2, npm `latest` 1.0.15;
   `server.json` advertises an npm version (1.4.1) that was never published.
2. The npm tarball ships ~9,100 lines of build-only governance code inside `mcp/lib/`
   (statically unreachable from `mcp/server.mjs`) plus ~4.6 MB of persona review corpora.
3. Onboarding defects: the documented Codex `/alpha` copy step cannot succeed after a
   marketplace install; `docs/INSTALL.md` contradicts the README (2 hosts vs 4, stale
   `<=30m` claim); OpenCode/Grok setup lives only in `AGENTS.md`.
4. Security: GUI markdown renderer XSS via unescaped `"` in attributes; GUI accepts any
   `Host` header (DNS rebinding); `gui/server.mjs` path resolution breaks on Windows;
   SSRF blocklist in `company-source-acquisition.mjs` is textual and follows redirects
   blindly; `getQuotes` drops the abort signal.
5. README: 4,858 words, internal contract vocabulary above the fold, no cost estimate,
   free first-run buried below install.

## WP3 — Security fixes (each with a regression test)

1. `gui/index.html` `esc()`: also escape `"` (and `'`). Add/extend a test that a report
   containing `[x](https://a"onmouseover=alert(1)")` renders with the quote escaped
   (there is an existing test layout under `test/`; a small jsdom-free string-level test
   of the inline() logic is acceptable — extract the renderer into a testable form only
   if it can be done without changing the page's behavior).
2. `gui/server.mjs`: reject requests whose `Host` header is not `localhost` or
   `127.0.0.1` (with optional port) with 403. Replace
   `new URL(".", import.meta.url).pathname` with `fileURLToPath` for Windows.
3. `mcp/lib/company-source-acquisition.mjs` `safeUrl` + fetch path:
   - Extend the blocklist: `0.0.0.0`, IPv6 loopback/link-local/ULA (`::1`, `fe80::/10`,
     `fc00::/7`), IPv4-mapped IPv6 (`::ffff:127.0.0.1` form), and decimal/octal/hex
     single-integer IPv4 encodings.
   - Resolve the hostname with `dns.promises.lookup({ all: true })` before fetching and
     reject when any resolved address falls in the private/loopback/link-local/metadata
     ranges. Fail closed on lookup errors.
   - Switch `redirect: "follow"` to `redirect: "manual"` and re-validate each hop with
     `safeUrl` + the resolution check, with a bounded hop count (5).
   - Keep zero-dependency: `node:dns` and `node:net` (`net.isIP`,
     `net.BlockList`) only.
4. `mcp/lib/quotes.mjs` `getQuotes`: thread the caller's `signal` through to each
   `fetchQuote` call.

Acceptance: new tests fail on the old code and pass on the new; `npm run check` green.
