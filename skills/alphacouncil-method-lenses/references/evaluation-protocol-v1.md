# Method Skill A/B protocol v1

Use the same anonymous, point-in-time evidence pack for all arms:

- `O`: current deterministic operator lens; freeze its native state, stance, rule IDs, tool outputs, and input hash.
- `S-shadow`: this Skill and the matching method reference without seeing `O`.
- `S-frozen`: this Skill receives `O` only after `O` is frozen and may explain but not alter it.
- `G`: generic analysis without a method reference, used as a negative control.
- `P`: raw public persona Skill when license permits testing, used only as a role-play and unsupported-claim control.

Representative methods: Buffett, Dalio, Simons, forensic short, Natenberg, and Bogle. Each category needs constructive, opposed, boundary, missing-critical-fact, partial-coverage, bad-unit/period, post-as-of, and wrong-instrument cases.

Measure stance/native-state match, decisive-rule precision and recall, numeric error, source-ID resolution, material-claim citation coverage, refusal correctness, unsupported numbers, fabricated quotes, impersonation, repeated-run consistency, behavioral differentiation, tokens, latency, and trigger collisions.

Hard gates for `S-frozen`: zero stance/hash rewrites; zero invalid sources, fabricated numbers, quotes, or impersonation; 100% rejection of bad hash/timestamp/unit and missing critical facts. `S-shadow` is research evidence only and cannot replace deterministic authority unless the full registered benchmark passes.
