# v1.5 package inventory evidence

WP2 is an evidence and assertion pass, not a size-targeted slimming exercise. Unknown
content remains in the package. The inventory is regenerated from the actual `npm pack`
file list; it does not trust the earlier audit's hand-written module list.

This reviewer record is repository-only and intentionally outside the npm publish list,
so its after-size row describes the tarball without changing that tarball itself.

## Reproduce

Run with lifecycle scripts disabled:

```bash
npm pack --dry-run --ignore-scripts --json
npm run package:inventory
npm run package:inventory:check
npm run test:package
```

`package:inventory` derives the static local-import closure of `mcp/server.mjs`, checks
every closure file is in the tarball, classifies every shipped path, and fails if a
required tree is incomplete or a forbidden test-only path is shipped.

## Removal decision

- `mcp/lib/personas-v2/ablation.mjs` and `mcp/lib/personas-v2/memory.mjs` had only test
  importers. They now live under `test/helpers/`, and both their old runtime paths and
  new helper paths are forbidden in the tarball.
- The complete 26-seat `knowledge/solo-test/masters/` tree, `knowledge/masters/`,
  `knowledge/ai-assisted-solo/reviews/`, solo-test formulas, and AI-assisted experiments
  stay shipped. The installed runtime, portable selfcheck, and shipped skill/package
  contracts still depend on those surfaces.
- Persona-v3 modules outside the server closure stay shipped because installed scripts
  and the portable selfcheck call them. Moving them would not remove them while
  `scripts/` remains an intentionally shipped check surface.

## Classification rules

- `runtime-required`: the 105-file server closure plus explicit runtime data and entry
  surfaces.
- `audit-surface-required`: shipped host, skill, documentation, fixture, and review
  contracts.
- `build-only`: installed build/check scripts and their proven inputs.
- `unknown`: evidence is insufficient; keep the path fail-closed.

The five current unknown paths remain deliberately packaged:

- `data/council-evaluation-protocol.v1.json` and
  `data/persona-v3-ai-assisted-solo-profile.v1.json` have no static JavaScript importer,
  but non-JavaScript consumers are not disproved.
- `data/persona-v3-semantic-adjudications.v1.mjs`,
  `data/persona-v3-semantic-skeptic-reviews.v1.mjs`, and
  `data/persona-v3-semantic-source-reviews.v1.mjs` each have a direct persona-v3
  build/check caller.

This evidence is T1 source inspection plus T2 installed-tarball exercise. It is not npm
registry verification, an external four-host/model live run, or PersonaPack-v3 GA
evidence.
