# v1.5 Codex plugin installation evidence

WP3 verifies the packaged Codex integration and corrects the current install surfaces. This
is T2 installed-artifact evidence. It is not a registry install, a live model research run,
or four-host T4/T5 evidence.

## User-facing contract

- Codex is Skill-first: install from the GitHub marketplace and invoke
  `@alphacouncil-agent <request>`. Explicit modes remain available, including
  `@alphacouncil-agent AAPL quick` and `@alphacouncil-agent AAPL news`.
- Claude Code, OpenCode, and Grok Build retain the host-native `/alpha` command.
- Full headless depth is selected at 15, 30, or 60 minutes. No current install surface
  advertises a universal 30-minute full run.
- A global npm install places the standalone MCP executable on `PATH`; it does not register
  the host-specific Skill, command, instruction, or generated-agent surfaces by itself.

## Reproduction

The review run used Codex CLI 0.146.1 and a fresh temporary `CODEX_HOME`. It built the
current tree with lifecycle scripts disabled, extracted the resulting tarball, and added
that extracted package as a local marketplace snapshot:

```bash
npm pack --silent --ignore-scripts --pack-destination <pack-dir>
tar -xzf <pack-dir>/alphacouncil-agent-1.4.1.tgz -C <source-dir>
CODEX_HOME=<isolated> codex plugin marketplace add <source-dir>/package --json
CODEX_HOME=<isolated> codex plugin add alphacouncil-agent@alphacouncil --json
CODEX_HOME=<isolated> codex plugin list --json
CODEX_HOME=<isolated> codex debug prompt-input '@alphacouncil-agent inspect install only'
node <mcp-probe> <installed-plugin-root>
node <installed-plugin-root>/scripts/package-smoke.mjs
node <installed-plugin-root>/scripts/check-install-docs.mjs
```

The user documentation deliberately keeps the real GitHub command
`codex plugin marketplace add Zhao73/alphacouncil-agent`. The local tarball marketplace is
the controlled test equivalent: both resolve the repository marketplace manifest, while
the test additionally proves the exact npm artifact contains every installed surface.

## Observed result

- The final WP3 tarball contained 1,151 files (2,061,731 compressed bytes and 8,744,121
  unpacked bytes); its package inventory had zero validation issues and retained the same
  five fail-closed unknown files documented in WP2.
- `codex plugin add` returned plugin ID `alphacouncil-agent@alphacouncil`, version `1.4.1`,
  and an installed cache path under the isolated home.
- `codex plugin list --json` returned `installed: true` and `enabled: true`.
- The installed `.codex-plugin/plugin.json`, `codex.mcp.json`, and
  `skills/alphacouncil-agent/SKILL.md` were byte-identical to the extracted tarball source.
- `codex debug prompt-input` produced 37,525 bytes and exposed five namespaced plugin
  Skills from the isolated cache, including
  `alphacouncil-agent:alphacouncil-agent`.
- A cold installed-server stdio probe recorded the complete JSON-RPC `initialize` and
  `tools/list` request/response pairs. The raw transcript was 43,943 bytes and listed
  exactly 34 tools.
- Installed `package-smoke.mjs` passed with 34 tools, 26 catalog entries, four locales,
  one selected method, and receipt replay rejected.
- The installed documentation gate passed with five authority files, four hosts,
  Skill-first Codex, three slash-command hosts, 15/30/60 tiers, and zero legacy patterns.

`CODEX_HOME` isolated every write and the target plugin cache/config. Codex also reads the
user-level `.agents` marketplace catalogue, so `plugin list --available` showed unrelated
personal marketplace entries read-only. The target install remained unambiguous because
every command selected `alphacouncil-agent@alphacouncil`, and every discovered target Skill
resolved into the temporary plugin cache.

`codex doctor` is not used as plugin-discovery evidence: in a fresh unauthenticated home it
correctly reports missing credentials and counts only user-configured MCP entries. The
model-visible Skill list plus the installed manifest/files and direct cold MCP handshake are
the relevant checks.

## Documentation gate precision

The automated gate scans only the five current authority surfaces:

- `README.md`
- `README.zh-CN.md`
- `README.ja.md`
- `docs/INSTALL.md`
- `AGENTS.md`

Historical `CHANGELOG.md`, `docs/releases/`, and `docs/plans/` records are intentionally
excluded. Contract tests prove the gate rejects a Codex `/alpha` table row, the old Codex
prompt-copy command, a universal `<=30m` claim, and a raw-GitHub curl installer without
misclassifying the three hosts that legitimately retain `/alpha`.
